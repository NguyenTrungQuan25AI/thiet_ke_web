# thiet_ke_web

> Website được xây dựng nhằm cung cấp một nền tảng web hiện đại, dễ sử dụng và dễ mở rộng.

## 📌 Giới thiệu

`thiet_ke_web` là dự án phát triển website với mục tiêu xây dựng giao diện trực quan, responsive và có cấu trúc mã nguồn dễ bảo trì.

## ✨ Tính năng

* Responsive trên desktop, tablet và mobile
* Giao diện người dùng trực quan
* Cấu trúc mã nguồn rõ ràng
* Dễ dàng mở rộng và bảo trì
* Tối ưu trải nghiệm người dùng


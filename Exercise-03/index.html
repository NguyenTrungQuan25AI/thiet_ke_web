BÀI 3: SMART NAVIGATION BAR

Hệ thống thanh điều hướng thông minh phản hồi theo kích thước màn hình: Menu hiển thị đầy đủ trên Desktop và tự động chuyển đổi sang Hamburger Icon & Thanh trượt ngầm (Off-canvas Drawer) trên Mobile.

💻 Trên Desktop (Màn hình rộng)

Hiển thị danh sách các thẻ liên kết ngang đầy đủ, trực quan và dễ tiếp cận.

.hamburger-btn { display: none; }

📱 Trên Mobile (< 768px)

Ẩn menu ngang, kích hoạt nút Hamburger 3 gạch mở thanh trượt ngầm mượt mà.

.desktop-nav { display: none; }
.hamburger-btn { display: flex; }

Tại sao không nên dùng cửa sổ pop-up hay if..else kiểm tra màn hình trong JS?

  • Chuẩn UI/UX cao cấp: Người dùng di động rất ghét việc bấm menu bị mở sang trang trắng mới hoặc nhảy pop-up che khuất. Một thanh trượt ngầm (Off-canvas Drawer) lướt êm ái từ mép màn hình mang lại cảm giác ứng dụng di động mượt mà (Native App Experience).
  • Tốc độ render vượt trội với CSS Media Queries: Thay vì dùng if..else trong JavaScript để liên tục lắng nghe sự kiện đổi kích thước cửa sổ (gây giật lag trình duyệt), CSS xử lý ở cấp độ nhân trình duyệt (Hardware Accelerated), tự động ẩn hiện tức thì khi người dùng xoay ngang/dọc điện thoại.
  • JavaScript chỉ giữ vai trò chuyển đổi trạng thái: JS chỉ làm một nhiệm vụ nhẹ nhàng nhất: kích hoạt class .is-active và .is-open khi người dùng nhấp vào nút Hamburger.

QUẢN LÝ THEME BẰNG BIẾN CSS

Trang web sử dụng 2 bộ biến màu tại :root (Chế độ Sáng mặc định) và lớp .dark-theme (Ghi đè chế độ Tối). Mọi chuyển đổi màu sắc, độ bóng và viền đều diễn ra êm ái nhờ hiệu ứng CSS Transitions.

🎨

Kiến Trúc Biến Màu

Toàn bộ màu sắc từ nền trang, thẻ nội dung, chữ cho đến thanh điều hướng đều được tham chiếu qua các biến CSS var(--bg-card), var(--color-primary).

Mã Nguồn Cốt Lõi: Ghi Đè Biến CSS Giữa 2 Chế Độ

/* 1. BỘ BIẾN MẶC ĐỊNH (SÁNG) TẠI :ROOT */ :root { --bg-page: #f6f3ed; /* Nền be ấm */ --bg-card: #ffffff; /* Nền thẻ trắng */ --color-primary: #1b4332; /* Xanh lá rừng đậm */ --color-text-main: #2d2926; /* Chữ than đen */ } /* 2. BỘ BIẾN CHẾ ĐỘ TỐI: GHI ĐÈ KHI BODY CÓ CLASS .dark-theme */ body.dark-theme { --bg-page: #0f1412; /* Nền đen ánh ngọc */ --bg-card: #18201b; /* Nền thẻ đen phiến đá */ --color-primary: #52b788; /* Xanh ngọc lục bảo tương phản cao */ --color-text-main: #f2f4f2; /* Chữ sáng dịu mắt */ }
